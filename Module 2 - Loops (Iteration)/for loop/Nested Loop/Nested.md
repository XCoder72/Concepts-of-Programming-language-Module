* Definition: 
A nested loop consists of one loop placed inside another loop, 
where the inner loop repeats for each iteration of the outer loop.

* Use:
Nested loops are used when working with two-dimensional data or repeated groups of work.

Examples:
Pattern printing
Chess board
Calendar
Seating arrangement
Matrix operations
Image processing

* Flow:
Outer Loop
     │
     ▼
Inner Loop
     │
     ▼
Execute Body
     │
     ▼
Inner Loop Ends
     │
     ▼
Next Outer Iteration

* Practice Problems
Easy

Print a 4 × 5 rectangle of numbers.

Medium
