* Definition:
A for loop is a count-controlled loop where the initialization, 
condition,and update are managed in a structured way.

* Why Do We Need?
When we know how many times a task should repeat.
Examples:
Print numbers 1–100.
Print a multiplication table.
Process 50 student records.
Traverse an array or list.


* Components:
Initialization
↓
Condition
↓
Body
↓
Update
The concept is the same as a while loop.

* while vs for :
while
Initialization
↓
Condition
↓
Body
↓
Update

All four parts are written separately.

for
Initialization;
Condition;
Update
↓
Body

Everything is organized in one statement.
