* Definition:

A Deque (pronounced deck) is a linear data structure in which elements 
can be inserted and removed from both the front and the rear.

* Why Do We Need?

Implementing queues and stacks.
Maintaining sliding-window maximum/minimum.
Managing tasks at both ends.
Supporting undo/history systems with access to both ends.

* Components:

Operation
Insert Front - Add at the front
Insert Rear	- Add at the rear
Delete Front - Remove from the front
Delete Rear	- Remove from the rear
Get Front	- View the first element
Get Rear	- View the last element

* Practice Problem:

Easy :
Create a deque and perform these operations in order:
1. Insert 20 at the rear.
2. Insert 10 at the front.
3. Insert 30 at the rear.
4. Remove one element from the front.
5. Remove one element from the rear.
6. Display the remaining deque.
