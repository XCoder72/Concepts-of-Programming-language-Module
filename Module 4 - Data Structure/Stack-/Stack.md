* Definition:

STACK - A linear data structure that follows LIFO — Last In, First Out, The element inserted last is removed first.

* Key Concepts:

> Push → add an element.
> Pop → remove the top element.
> Top/Peek → see the top element without removing it.
> LIFO → last inserted element comes out first.
> Python can use list as a stack; C++ provides std::stack.

Example - An Stack of Plates you put A new plate on top, and when removing one, you take the top plate first.
