* Definition:
Scope determines where a variable can be accessed in a program.

The two basic scopes we'll focus on are:

Local → available inside a function/block.
Global → available throughout the relevant program/file.

Local Variable
A variable created inside a function is generally a local variable.

Global Variable
A variable declared outside functions can have global scope.
