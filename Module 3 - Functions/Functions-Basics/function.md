Definition :-
A function is a reusable block of code 
designed to perform a specific task.
Instead of writing the same logic repeatedly, 
write it once inside a function and call it whenever needed.

Key Concepts :-
Define → create the function.
Call → execute the function.
Parameter → input received by the function.
Return value → result sent back by the function.
Functions make programs modular, reusable, and easier to maintain.

flow :-
Define function
      ↓
Call function
      ↓
Function executes

Functions can later be classified by:
No parameters / parameters
No return / return value
Default arguments
Multiple parameters
Recursive functions
Lambda functions
