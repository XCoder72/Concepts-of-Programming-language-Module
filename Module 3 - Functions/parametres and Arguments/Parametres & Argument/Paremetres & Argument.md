* Definition:
Parameters allow a function to receive data from outside. 
This makes one function reusable with different values.

An argument is the actual value supplied when calling the function

Parameter Can be multiple depend on needs.

returntype ---> Parametres ---> Argument ---> Function ---> return.

* datatype of parametres independent of function datatype.

* Key Concepts
A parameter is a variable defined in the function.
An argument is the actual value passed during the function call.
A function can have one or multiple parameters.
The same function can process different values.
Parameter order matters when using positional arguments.
